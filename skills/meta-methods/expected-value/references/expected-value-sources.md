# Expected Value Sources

Reviewed 2026-05-27.

## Core Sources

- Stanford Encyclopedia of Philosophy, "Normative Theories of Rational Choice: Expected Utility", https://plato.stanford.edu/entries/rationality-normative-utility/.
  - Grounding used: expected utility ranks acts under uncertainty; expected utility is a probability-weighted sum of outcome utilities; utilities and probabilities must be defined before comparing acts.
- Stanford Encyclopedia of Philosophy, "Decision Theory", https://plato.stanford.edu/entries/decision-theory/.
  - Grounding used: decision theory centers on preferences, prospects, and choices under uncertainty, with expected utility as a central normative rule in many uncertainty cases.

## Skill Interpretation

This skill deliberately teaches the operational agent procedure, not the full philosophical debate over expected utility theory. It uses:

- "expected value" for probability-weighted payoff in a shared value unit,
- "expected monetary value" when that unit is money,
- "expected utility" when money or another raw measure is nonlinear with preference,
- hard constraints for ruin, privacy, legality, safety, and other veto conditions that should not be averaged away.

## Boundary Notes

- `bayesian-reasoning` updates probabilities from evidence; this skill uses accepted probabilities to choose among actions.
- `second-order-thinking` expands the consequence chain before outcomes are modeled; this skill weighs modeled outcomes.
- `prioritization` ranks broad work with mixed criteria; this skill handles quantified decision comparisons.
- `constraint-awareness` defines the feasible set before optimization; this skill optimizes only inside that feasible set.
