# McKinsey 7S Sources

Reviewed 2026-06-08T00:03Z.

## Concept Sources

- McKinsey Quarterly, "Enduring Ideas: The 7-S Framework."
  - URL: https://www.mckinsey.com/capabilities/strategy-and-corporate-finance/our-insights/enduring-ideas-the-7-s-framework
  - Used for: the official McKinsey framing that 7S was introduced to address coordination rather than structure alone, maps interrelated factors influencing an organization's ability to change, and remains a tool for understanding organizational complexity.
- McKinsey Quarterly, "A new operating model for a new world."
  - URL: https://www.mckinsey.com/capabilities/people-and-organizational-performance/our-insights/a-new-operating-model-for-a-new-world
  - Used for: current McKinsey context, the explicit seven-element list, the statement that 7S has been refreshed into the 12-element Organize to Value system, and the boundary between classic 7S and modern McKinsey operating-model redesign.
- Waterman, Robert H., Thomas J. Peters, and Julien R. Phillips, "Structure is not organization," Business Horizons, 23(3), 14-26, 1980.
  - URL: https://www.sciencedirect.com/science/article/pii/0007681380900270
  - DOI: https://doi.org/10.1016/0007-6813(80)90027-0
  - Used for: original publication record behind the framework's core warning that organization cannot be reduced to formal structure.

## Authoring Interpretation

The skill treats McKinsey 7S as an internal organization-alignment and change-readiness framework. The operating sequence is:

1. Define the organization, strategic change, decision, time horizon, and privacy boundary.
2. Map shared values, strategy, structure, systems, style, staff, and skills.
3. Separate current state, target state, evidence, assumptions, and uncertainty for each element.
4. Diagnose fit, contradictions, and reinforcement among elements.
5. Prioritize root causes rather than recommending one fix per heading.
6. Convert the diagnosis into interventions, owners, sequencing, and monitoring signals.

The skill preserves the classic 7S framework because users explicitly ask for it, but it does not present it as the only current McKinsey operating-model lens. The 2025 Organize to Value source is included so the agent can disclose the newer model when the user asks for current McKinsey operating-model redesign rather than the classic 7S diagnostic.

## Boundary Notes

- Porter's Five Forces owns external industry structure and profit-pressure diagnosis.
- Value Chain Analysis owns activity-level value, cost, margin, and linkage diagnosis.
- VRIO owns resource/capability durability testing through value, rarity, imitation cost, and organization.
- SWOT/TOWS owns broad internal/external factor inventory and option generation.
- OKRs own objective and key-result setting and execution tracking.
- Playing to Win owns integrated strategy-choice formulation.
- McKinsey's 2025 Organize to Value system is a newer McKinsey operating-model design frame; it should be named when the user asks for current McKinsey operating-model redesign, but it does not erase the usefulness of a classic 7S analysis when the user asks for 7S.
