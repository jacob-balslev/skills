# Lean Startup Sources

Checked 2026-06-14 with web search and page fetches against public Lean Startup sources.

## Primary Sources Used

- `https://theleanstartup.com/principles` — Eric Ries / The Lean Startup methodology page. Used for the core method frame: scientific approach to creating and managing startups, testing a vision continuously, MVP, build-measure-learn, actionable metrics, Five Whys, pivot/persevere, validated learning, and innovation accounting.
- `https://leanstartup.co/about/principles/` — Lean Startup Co principles page. Used for the five-principle summary: entrepreneurs are everywhere, entrepreneurship is management, build-measure-learn, validated learning, and innovation accounting.
- `https://leanstartup.co/resources/articles/what-is-an-mvp/` — Eric Ries MVP explainer. Used for the distinction between an MVP as maximum validated learning with least effort and the common mistake of treating MVP as merely a minimal product.

## Authoring Decisions

- The skill is placed under `reasoning-strategy` because it teaches a decision and validation methodology for uncertainty, not a product-domain convention or software delivery practice.
- `taxonomy_domain: foundations/product-strategy` matches neighboring strategy skills such as `kano-model` and keeps product-validation methods browsable within the reasoning-strategy shelf.
- The body emphasizes designing the experiment backward from learning to measurement to build. This is an operational guardrail: agents otherwise overbuild and then search for metrics after the fact.
- The skill does not claim Lean Startup replaces customer research. Generative research can produce candidate problems and hypotheses; Lean Startup tests explicit assumptions through behavior evidence and learning milestones.
- The skill treats MVP forms such as smoke tests, fake-door tests, concierge tests, wizard-of-oz tests, prototypes, pilots, pre-orders, and manual service tests as experiment options, not as a fixed maturity ladder.

## Evidence Notes

- Stable method claims can rely on the public Lean Startup method pages and Eric Ries's MVP explainer.
- Current-market claims, tool claims, or claims about a user's specific market still require task-time research; this skill only teaches the validation method.
- URL truth sources remain external and should be re-fetched when a future audit needs truth certification.
