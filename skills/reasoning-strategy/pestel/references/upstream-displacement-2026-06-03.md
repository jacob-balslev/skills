## Finding

No upstream displacement found.

Recent agent-platform and CLI releases improve the runtime environment for agents: model behavior, tool use, file handling, code execution, SDKs, memory, workflows, and automation surfaces. None replaces the PESTEL method itself: scoping an external environment, scanning political/economic/social/technological/environmental/legal forces, separating external signals from internal factors, judging evidence and uncertainty, and converting signals into opportunities, threats, assumptions, and monitoring triggers.

Better models may perform PESTEL analysis more fluently, but the method still needs explicit teaching because the common failures are structural: unsourced trend lists, internal factors mislabeled as macro forces, geography-free claims, legal/political collapse, and treating a six-heading table as a completed strategy.

## Recommendation

Create and keep the skill. Treat current agent platforms as improved execution environments for PESTEL analysis, not as substitutes for teaching the framework in a portable agent skill.
